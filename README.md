# Soviet-Strength-Programming
This is a python script to help create a Strength Program based on the Soviet System, inspired by Pavel Tsatsouline and StrongFirst programming.

Script can be adapted for any compound lifts for 4 week periods. 
Main idea behind soviet system is to randomise BOTH Intensity and Volume over time, while keeping load the same. 
After the load becomes easy, you retest 1RM and usually make a big jump up in weight. 
So unlike the western system of linear progression and deloading weeks, this is a different and superior approach.
